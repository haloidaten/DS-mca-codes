# 📚 Data Structures and Algorithms in C

Welcome to my **Data Structures and Algorithms (DSA) repository!** 🚀

This repository contains C programs implemented to understand and practice fundamental data structures, searching algorithms, sorting techniques, and set operations.

The programs demonstrate how different data structures work through practical implementations and menu-driven programs.

## 💻 How to Run the Programs

Follow these steps to compile and execute the programs on your computer.

### Step 1: Clone the Repository

Open your terminal and run:

```bash
git clone <your-repository-url>
```

Replace `<your-repository-url>` with the URL of your GitHub repository.

### Step 2: Navigate to the Project Folder

```bash
cd <repository-folder>
```

Replace `<repository-folder>` with your repository's directory name.

### Step 3: Compile a C Program

For example, to compile `p2.c`:

```bash
gcc p2.c -o p2
```

### Step 4: Execute the Program

**On Linux or macOS:**

```bash
./p2
```

**On Windows:**

```bash
p2.exe
```

### Running Other Programs

Replace `p2.c` and `p2` with the desired source filename and executable name.

For example:

```bash
gcc p3.c -o p3
./p3
```

Repeat the process for the remaining programs.

> **Note:** Some programs use compiler-specific headers or language features. A compatible compiler may be required.
